# ScareCroft Indonesia — Official Landing Page

Selamat datang di repositori resmi landing page **ScareCroft Indonesia**. Kami adalah studio pengembangan perangkat lunak (*software house*) yang menyediakan solusi digital komprehensif, mulai dari pembuatan Landing Page kilat hingga Sistem Aplikasi Kustom berskala korporat.

## 🚀 Fitur Utama Website
- **Arsitektur Modern:** Dibangun menggunakan bundler super cepat **Vite** dan framework **Tailwind CSS v4** berbasis pendekatan *CSS-first*.
- **Desain Premium:** Menggunakan implementasi *Glassmorphism Navbar* yang responsif untuk berbagai perangkat (termasuk optimasi khusus layar iPad Pro 13 inci).
- **Animasi Sinematik:** Dilengkapi dengan efek *Intro Cinematic Logo Jump* dan *Ambient Glow Background* yang interaktif.
- **Dual Theme Switcher:** Fitur pengalih *Dark Mode* dan *Light Mode* kustom yang bergeser mulus dengan animasi slider.
- **Optimasi SEO & Performa:** Memuat struktur meta tag yang ramah mesin pencari, Open Graph untuk pratinjau tautan media sosial, serta file `sitemap.xml` yang terintegrasi dengan Google Search Console.

## 🛠️ Teknologi yang Digunakan
- **Frontend Core:** HTML5, Modern JavaScript (ES6+), CSS3
- **CSS Engine:** Tailwind CSS v4
- **Build Tool / Bundler:** Vite
- **Platform Deployment:** Vercel (Integrated via GitHub Actions / Continuous Deployment)

## 💻 Cara Menjalankan Proyek secara Lokal

Untuk menjalankan dan mengembangkan proyek ini di komputer lokal Anda, ikuti langkah-langkah berikut:

1. **Clone Repositori:**
   ```bash
   git clone https://github.com
   cd scarecroft-indonesia
   ```

2. **Instal Dependensi:**
   Pastikan Anda sudah menginstal Node.js, lalu jalankan perintah:
   ```bash
   npm install
   ```

3. **Jalankan Server Development:**
   Mulai server lokal untuk melihat perubahan kode secara real-time:
   ```bash
   npm run dev
   ```
   Buka alamat `http://localhost:5173` (atau port yang tertera di terminal) pada browser Anda.

4. **Kompilasi Produksi (Build):**
   Untuk membuat aset produksi yang diminifikasi dan dioptimasi:
   ```bash
   npm run build
   ```
